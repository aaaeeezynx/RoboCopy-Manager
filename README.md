# RoboCopy Manager

基於 **robocopy** 的 Windows 備份工具，提供圖形介面、任務排程、系統通知與檔案總管右鍵整合，讓你不需要記任何指令就能完成可靠又快速的檔案同步與備份。

![Tech](https://img.shields.io/badge/Tauri-2.0-blue) ![Tech](https://img.shields.io/badge/React-19-blue) ![OS](https://img.shields.io/badge/Windows-10%2B%20x64-lightgrey)

---

## ✨ 特色

- **圖形化操作**：來源／目的地拖曳或瀏覽，免背 robocopy 指令
- **單檔或資料夾**：不只資料夾對資料夾，也能複製單一檔案到指定資料夾
- **五種情境**：只加新檔、同步更新、完整鏡像、模擬測試，一鍵套用
- **進階參數**：鏡像、保留權限、可續傳、只覆蓋較新檔等，可自由開關
- **排除清單**：內建開發／媒體／攝影等排除範本，也可手動加
- **任務管理**：儲存設定、多選批量執行、匯入／匯出任務
- **執行歷程**：自動記錄最近 100 次備份結果
- **系統通知**：完成時顯示複製了多少檔案、用時與速度
- **主題自訂**：深色／淺色／跟隨系統，輔以系統強調色
- **右鍵整合**：檔案總管右鍵直接「複製到」或快速選擇路徑
- **系統匣**：背景執行狀態、快速操作

## 🚀 安裝

下載 `RoboCopy Manager_x64-setup.exe` 並執行，或直接使用 `.msi`。

> 首次執行可針對多個檔案選取右鍵選單整合，於「設定」頁開啟。

### 開始使用

1. 啟動後預設停在 **快速執行** 頁
2. 選擇「單一檔案」或「資料夾」模式
3. 拖曳或以瀏覽按鈕填入 **來源** 與 **目的地**
4. 點「開始備份」（或按 `Ctrl+Enter`）
5. 完成時收到系統通知，並可在「執行」下方看結果與日誌

## 🛠 開發

```bash
# 安裝依賴
npm install
```

## ⚡ 相較系統內建（Copy／xcopy／剪貼簿檔案總管）的優勢

**1. 多緒與增量，速度更快**

- robocopy 支援**多執行緒**（`/MT`，預設 8 緒），大批中小檔案時可比單緒的檔案總管拖曳／`xcopy` 快上數倍。
- **可續傳**（`/Z`）：大檔案傳輸中斷後可從斷點續傳，不必整個重來。
- **只複製差異**：搭配 `只覆蓋較新檔`（`/XO`）或 `同步更新`（`/MIR`）情境，已同步過的舊檔直接跳過，第二次以後備份接近即時完成。

**2. 更可靠的斷線與重試**

- 內建重試機制（`/R`、`/W`）：來源暫時鎖定或網路抖動時自動重試，不像檔案總管一斷就跳錯誤。
- 精準的退出碼（exit code bitmask）區分「有檔案被複製／有未符／有失敗／嚴重錯誤」，判斷備份是否真正成功。

**3. 可管、可控、可預覽**

- **模擬測試**（`/L`）先列出將執行什麼，避免誤刪。
- **排除清單**精準跳過 `node_modules`、`Thumbs.db` 等不必備份的內容。
- **完整日誌**與**執行歷程**，可事後稽核每次備份做了什麼。

**4. 可重複自動化**

- 任務可儲存、批量執行、匯入匯出，一次設定反覆使用。
- 保留 NTFS 權限（`/COPY:DATSOU`）、時間戳等中繼資料，跨磁碟搬移不像檔案總管會丟失屬性。

> 上表為一般性比較，實際速度會依檔案數量、大小、硬碟與網路環境而異。

## 🔒 隱私與安全

- 所有資料僅存在本機（localStorage），**不上傳任何內容**。
- 備份路徑、帳號名稱等個人資訊不會被收集。
- 適用於備份**你有權限存取**的資料。
